# SmartCart Clustering System
SmartCart Clustering System is an unsupervised customer segmentation solution designed for the SmartCart e-commerce platform. This project leverages clustering algorithms to analyze customer demographics, purchase behavior, and engagement data, enabling SmartCart to identify distinct customer groups and drive data-driven marketing strategies.
# Key Features
- Comprehensive Data Analysis: Utilizes a dataset of 2,240 customers with 22 attributes, including demographics, spending patterns, and engagement metrics.
- Clustering Algorithms: Applies unsupervised machine learning techniques to discover hidden patterns in customer behavior.
- Actionable Insights: Supports personalized marketing, customer retention, and early identification of churn-prone users.
- Flexible Data Inputs: Handles various customer attributes such as income, family composition, product spending, purchase frequency, and feedback.
# Example Use Cases
- Segmenting customers for targeted promotions (e.g., high spenders on wine or gold products)
- Identifying loyal customers based on purchase frequency and recency.
- Detecting at-risk customers for proactive retention campaigns.

This repository is ideal for data scientists, ML engineers, and marketing analysts seeking to enhance customer understanding and engagement on e-commerce platforms.
